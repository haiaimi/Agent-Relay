# 验证范围 · 2026-11-02

环境：Windows、Node 24.14.0、Codex CLI 0.161.0、Claude Code 2.1.316；服务器为 Ubuntu。以下为实现过程的验证记录，不表示未来版本或所有设备均通过。

## 已验证

- 类型检查、构建、前端脚本语法检查与 29 项自动测试通过。覆盖登录/来源校验、路径与 junction 边界、历史分页与压缩读取、Codex project 及多根 workspace 归属、原生状态/标题对账、流式回复、审批、停止、模型预设、操作去重、队列和离线缓存。
- 本机和公网 HTTPS → WSS → 本地 Agent 链路：Codex / Claude 分别新建、连续续聊和下轮模型/强度切换；浏览器显示原生历史与 AI 文字，工具默认折叠。
- Claude 旁问、命令补全和任务执行期间排队；协议测试覆盖 Claude 原生/托管及 Codex 托管/桌面的逐条引导、拒绝回队和投递未知时不重发。
- 真实桌面 owner 发现与能力显示已验证；没有向用户正在执行的真实任务注入引导测试。桌面真实模型接收仍需使用中验收。
- 390px 响应式浏览器中验证紧凑头部、输入框焦点/增高、实际指针左右拖动侧栏。布局对比正文高度由约 46% 增至 77%；不是 iPhone 实机键盘结果。
- 图片/文件上传经过公网中转到真实电脑，上传及下载 SHA256 一致；未登录下载返回 401。新增测试覆盖资源隔离、内容校验、Codex/Claude 图像输入、带图引导和离线下载。上传验证未向真实任务发送测试消息。
- HTTPS 证书、relay/nginx 运行及发布资源一致性检查通过；证书续期定时器已配置。

- iPhone 真机键盘、相机/相册、拖动手感、蜂窝网络与网络切换。
- Docker 容器实际运行、长期后台稳定性和证书长期自动续期。
- 真实高风险写入或提权命令审批；隔离协议测试不代替真实操作验收。
- 新版 Codex / Claude 与桌面原生 IPC 的兼容性。
