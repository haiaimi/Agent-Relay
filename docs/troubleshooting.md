# 故障排查

## 设备离线或对话一直排队

先核对设备 ID、工程与会话来源，再检查电脑端 bridge 进程、服务日志和服务器连接。Codex 桌面退出不应终止独立 bridge；电脑休眠、断网、退出登录仍会离线。Windows 安装后台任务的方法见 [部署指南](deployment.md)。

“已完成”加“排队中”表示原轮已结束但后续输入尚未被接收，不代表新一轮正在运行。`already has an active writer` 是会话写入所有权冲突；不要重发消息或删锁文件。应通过原生所有者通道继续，或等待所有者释放。macOS 检查同一用户下的 `$CODEX_HOME/ipc/ipc.sock`，默认 `~/.codex/ipc/ipc.sock`；旧连接程序只配置 Windows 管道时，需要更新电脑端构建并安全重启。模型选择失败与写入所有权问题要分开诊断。

若投递结果未知，先查看本机会话及保存的操作回执，再决定是否重试。连接失败可按运维要求重试，但不能把同一业务操作换新 ID 反复发送。当前设备是否在线应以 API 状态及一次真实只读请求共同判断，不能仅看进程存在。

## 原画或交付图片缺失

确认图片属于当前需求的工作副本，且在当前任务 `artifacts` 清单内。检查原文件存在、格式可解码、文件身份与声明一致、工作电脑在线；点击重新加载读取本轮原件。历史消息中的本机绝对路径不是手机可直接访问的网址。

旧版交付页从历史图片索引渲染，可能混入重复引用或加载不到的路径。新版根据真实交付清单和任务来源取图。预览成功后，审批还会核验本机原件；不要仅凭缓存缩略图跳过确认。

## 展示视频不能播放

确认录制任务输出真实 MP4/WebM/MOV 文件，并在交付清单中声明。优先 H.264、yuv420p、faststart MP4。检查浏览器收到 `video/*`、`Accept-Ranges: bytes`，合法范围返回 206，越界返回 416。工作电脑必须在线，服务器不会持久存储此类成果视频。静态方案轮播必须明确标注，不能代替真实游戏运行验收。

## 流程阻断、工具缺失与旧场景

任务详情显示依赖、执行记录和具体阻断原因。优先用工具发现脚本核对 Blender、Python 解释器及依赖，而不是只搜索当前 PATH。引擎哈希变化、入口文件变化、缺少工具和视觉不符合属于不同问题，报告应说明检查范围、证据与补救方法。

恢复使用原会话和工作副本；完成节点不会重新拆解。可选择跳过并继续，但跳过不代表验收通过，记录需保留。实际场景验收必须运行本需求的入口、记录加载的场景，并与批准参考对照；旧场景截图或单纯哈希检查不能替代。

若跳过窗口要求先停止却没有停止按钮，先刷新页面并核对窗口中的具体会话。旧版会将已经结束的「历史记录」误判为未结束；新版在完成报告、匹配回执和时间检查通过后允许直接跳过。真正运行或排队的会话会显示对应操作；状态读取失败每分钟重试一次，最多五次。仍未确认的投递需先核对记录或绑定本次会话，不能通过跳过掩盖未知执行。

## 手机布局或缓存异常

侧边栏由共享工作台统一控制；工作室切换后显示需求进度。若出现旧的双抽屉或旧布局，先核对服务器静态文件版本，再刷新。iPhone 键盘相关逻辑使用可视视口约束与输入框字号；桌面模拟不等于真实 Safari/主屏幕模式验证。

会话缓存用于切换时立即显示已读内容，再增量更新；不能作为服务在线或任务完成的证明。退出登录清理网页设备缓存，服务器历史和普通媒体缓存按独立策略保留。
