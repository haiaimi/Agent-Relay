# 2026-11-05 功能与验证记录

本记录覆盖 Agent Relay 工作室、会话工作台及桌面入口的本轮合并。生产数据与真实素材不随代码发布。

## 变更范围

- 项目组按职能分配 Agent、模型与权限；独立工程路径与每需求 Git 工作副本。
- 可选制作阶段与审批：玩法/LD、原画、制作人视觉确认、规格/资产、程序与场景集成、QA、最终交付。拒绝后按反馈回到原任务；提供断点继续、复核、重试及带原因跳过。
- 职能聊天、任务过程记录、团队群聊；项目组上下文中的头脑风暴可选择模型并转生产需求。
- 统一工作台侧边栏、移动端会话列表与进度、抽屉手势、键盘视口及浏览器会话缓存。
- 用户附件去重并移除内部路径提示；SVG/Mermaid 图表与媒体展示。
- 原生 Codex 下一轮模型偏好持久化；写入所有权冲突时保留消息；macOS/Linux 原生 IPC socket 发现，避免无效续聊导致假执行状态闪烁。
- 原画预览缓存与批准时原件哈希核验；交付媒体改读声明的实际文件，去重并保留来源任务。
- 可选成果展示视频任务及已完成需求补录入口；视频保存在工作电脑，经服务器按范围流式中转，不持久写入服务器。
- Windows 独立后台任务、桌面入口和工具发现脚本。
