# 返工、持续对话与主干合入

角色对话把交付预览、消息记录和输入区分别限制在窗口内。大图、视频和待验收内容在预览区滚动，输入区保持可用。

未最终验收的需求，可打开具体制作任务，选择“提出修改要求”。返工表单支持选择、粘贴及拖入图片、视频和文件，最多 5 个、合计 16 MB。附件传到该需求的工作电脑，返工记录保存附件引用；执行 Agent 收到附件，受影响的下游重新执行。最终汇总任务返工只重写报告；产品问题应选具体制作任务。旧执行记录保留。

验收和合入是独立操作。只点“验收通过”不会提交或修改主干。在最终验收区或已验收需求详情里，点“验收并合入主干…”或“合入主干…”，填写目标本地分支（默认 main，可改成 master 或其他现有分支）。有跳过项时仍需明确确认遗留问题。程序 Agent 在对应电脑和独立工作副本中执行合入任务。

合入任务先核对仓库、所有 worktree、HEAD、未提交变更和交付清单，只整理本需求可归属的文件。本地提交及合入由用户点击该选项授权，不包含远程 push 或发布。目标有无关未提交工作、冲突、并行写入、缺失分支或文件归属不明时，Agent 应停止并报告，不能 stash/reset/clean/force。先在独立整合 worktree 试合并和验证，核对目标未变化后再正常合入；保留原需求副本和日志。

`studio_mainline_jobs` 单独保存投递请求及执行会话。相同请求 ID 不重复启动；超时显示“投递未确认”，不自动重发。UI 区分“正在执行”和“Agent 已返回合入报告”；报告是 Agent 提交的实际 SHA、命令和检查证据，不是服务器独立执行的 Git 验证。可打开完整合入记录复核。
