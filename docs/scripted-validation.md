# 脚本优先的制作与验收

Relay 下发的新计划、制作任务、旧会话续做和自动补做默认通过本机脚本执行，不依赖 Computer Use、Finder 或 App 绑定。旧计划由 Agent 自行增加的桌面控制门禁不能阻止受支持的脚本验证；制作人明确要求的业务验收、人工试玩和审批仍须保留。

优先复用工作副本内的启动、测试和录制脚本，运行本需求实际场景，核对移动、交互、胜利、重置及所选阶段需要的画面和冷加载等结果。不得换成旧入口，也不能重复制作一套实现来完成测试。外部共享工具可以按现有规则只读执行，产物仅写本需求工作副本。

报告应列明引擎、工作副本、入口、命令、实际日志、检查结果和媒体路径，并区分：

- 引擎自动输入、系统脚本输入、人工输入。
- 引擎帧导出或离线影片、实际窗口或桌面实时录屏。
- 功能断言通过、实际画面验证和真实 CPU/GPU 性能测量。

离线影片不能证明实时性能；自动输入不能冒充人工试玩。媒体须实际解码和检查内容，不能用静态图拼接或旧场景替代。视频保留在工作电脑，由 Relay 鉴权转发，不在服务器持久存储。

脚本仍受 macOS 录屏、辅助功能等实际权限和当前会话工具约束限制。能力缺失时报告具体操作、证据和最小恢复步骤，根因未知就明确未知；不能仅因 Computer Use 超时就断言 Finder 不可访问。保留失败与未执行项，环境不变时不无限重复绑定。连接失败最多五次，每次间隔一分钟；写入或启动结果未知时先核对回执、PID和日志，不盲目重放。

此规则由 `src/relay/studio-rendering.ts` 的共享指令注入。更新 Relay 服务即可对后续下发任务生效；正在运行的旧会话需要一次当前阶段指引，或在下一轮续做时获得新指令，不会因此重建任务或工作副本。
